Rahat Architecture

Miya is the agent you talk to. Rahat is everything underneath it: the doors messages come in by, the rules in code that meet them, the specialists, the checks between an answer and you, the memory they share, and the jobs that keep it fed while nobody is typing. It runs on one Mac mini at home.

The discipline

The rails

Before a change ships

  • A fix adds a pinA fix: commit without a new regression test is refused at merge. 219 pin files, 1,877 tests.
  • Hermetic tests4,209 tests, no network, no live database, no secrets loaded.
  • The pre-push gatePrivate words, the bug-to-test policy, the registry, the silent-failure guard, the unit and contract layers. Anything red blocks the push.
  • Private wordsA name, an address, a token or a chat id in anything a push would publish stops it.

In production

  • Model calls endA 90-second timeout on the shared client, a retry on a provider hiccup, and “still checking” when a Bourdain ask runs long.
  • Messages landA reply Telegram refuses for its formatting goes again as plain text; a nudge that doesn't land is tried again the next minute.
  • It tells on itselfOne line at 08:15 when something is broken; silence when nothing is.
  • Spend is visibleEvery billable event in the cost ledger, shown by /cost; each harness ask runs under a brake.

Shipped and the bet

Where it's going

Outcomes, not answers

Measured for two agents; learning not built

Bourdain's answers and Fraser's designs are checked against named outcomes and recorded, and Bourdain's golden set replays for nothing. A loop that changes behavior from outcomes isn't built.

Memory that keeps what mattered

Not built

Shared typed memory is in daily use. Recall weighted by what changed an outcome, rather than by what was recent, is the bet.

A receipt for every fact

Partial, one agent

Bourdain's facts carry their source and date, from the web, open data and the feeds. The profiles, memory and training numbers don't yet.

Next on the data path: the database answers first, code applies the facts (who is eating, how far, open now), the model applies taste once, and the web is touched only when the database comes up short or you say “search”. That path isn't built yet.
